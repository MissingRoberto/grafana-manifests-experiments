# Business

Executive and go-to-market dashboards: KPIs, revenue, sales pipeline and user
engagement.

These dashboards are intended for a business audience. Numbers are aggregated
and refreshed daily unless noted otherwise.

## Dashboards

| Dashboard | Purpose |
|-----------|---------|
| KPI Overview | Headline company metrics at a glance |
| Revenue Metrics | Recurring revenue, churn, expansion |
| Sales Pipeline | Deal stages, conversion, forecast |
| User Engagement | Active users, retention, feature adoption |

See **Contributing** for how to propose changes to these dashboards.
